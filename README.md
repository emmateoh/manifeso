# Manifeso Trading Contracting & Services

Website for manifesotrading.com: CCTV installation, structured cabling and fiber splicing in Qatar.

- The public site is in `site/` (plain HTML, CSS and a little JavaScript, no build step).
- Pushing to `main` deploys it to GitHub Pages (`.github/workflows/static.yml`).
- Contact form: replace `YOUR_FORM_ID` in `site/contact.html` with your Formspree form ID. Until then, the form opens WhatsApp with the message filled in.
- New project photos go in `site/img/projects/` (WebP, 640px and 1200px wide).
